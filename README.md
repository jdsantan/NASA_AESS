# ASTRIA · HRP Health Monitor

Prototipo de NASA Space Apps Challenge para explorar el registro de salud a bordo, el triaje simulado y la sincronización diferida de reportes.

## Ejecutar en local

Requiere Node.js 20 o posterior.

```sh
npm install
npm run dev
```

Abre la dirección que muestra Vite. Para generar el sitio estático, ejecuta `npm run build`.

## Demostración

1. Selecciona un entorno y un escenario simulado.
2. Revisa los indicadores, el mapa corporal y las alertas.
3. Simula un corte, registra un reporte y restablece el enlace.

El prototipo guarda su estado en el navegador y simula la entrega de reportes. Usa datos e imágenes ficticios. Los criterios de demostración requieren validación para cualquier uso clínico.
